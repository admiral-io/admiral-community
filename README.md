# Admiral community

The place to report a bug, ask for a feature, or ask a question about
[Admiral](https://admiral.io/?utm_source=github&utm_medium=referral&utm_campaign=admiral-community).

Admiral is a control plane for coordinating infrastructure and application
delivery across environments. It orchestrates the Terraform or OpenTofu,
Helm and Kubernetes manifests you already have, keeps the dependency graph
across them, and uses self-hosted agents that make changes inside your own
accounts and clusters.

## Where to go

| You want to | Go to |
| --- | --- |
| Report a bug | [Open an issue](https://github.com/admiral-io/admiral-community/issues/new/choose) |
| Suggest a feature or change | [Open an issue](https://github.com/admiral-io/admiral-community/issues/new/choose) |
| Ask a question or share how you use Admiral | [Start a discussion](https://github.com/admiral-io/admiral-community/discussions) |
| Report a problem in the docs | [Open an issue](https://github.com/admiral-io/admiral-community/issues/new/choose) |
| Report a security vulnerability | Email [security@admiral.io](mailto:security@admiral.io). Never a public issue. |
| Reach us privately | Email [support@admiral.io](mailto:support@admiral.io) |

Not sure whether something is a bug or which part of Admiral it belongs to?
Open it here. We move issues to the right place.

If you are working in one of the open-source repositories below and the
problem is in that code, you can also open the issue in that repository.

## Before you open an issue

- Search [existing issues](https://github.com/admiral-io/admiral-community/issues?q=is%3Aissue)
  first. A thumbs-up on an existing one tells us more than a duplicate.
- Include versions, what you ran, and what you saw. Remove API keys, tokens
  and anything else secret from logs before you paste them.
- One problem per issue.

Everyone here follows the
[Code of Conduct](https://github.com/admiral-io/.github/blob/master/CODE_OF_CONDUCT.md).
